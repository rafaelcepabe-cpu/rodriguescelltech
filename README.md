# Rodrigues CellTech 📱💻

Site institucional desenvolvido para a **Rodrigues CellTech**, assistência técnica especializada em manutenção de celulares e computadores.

## 📌 Sobre o projeto

O objetivo deste projeto é criar uma presença digital para a Rodrigues CellTech, apresentando de forma simples e profissional os serviços oferecidos pela assistência.

O site foi desenvolvido pensando em facilitar o contato dos clientes e divulgar os principais serviços realizados pela empresa.

## 🛠️ Serviços apresentados

* Manutenção de celulares
* Troca de tela
* Troca de bateria
* Troca de câmera
* Troca de placa
* Manutenção e instalação de Windows 11
* Limpeza de computadores
* Montagem de computadores

## 💻 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

## 🎨 Características

* Layout responsivo
* Design moderno
* Identidade visual da Rodrigues CellTech
* Apresentação dos serviços
* Botões para facilitar o contato com a assistência
* Estrutura adaptada para computadores e celulares

## 🎯 Objetivo

Este projeto foi desenvolvido com o objetivo de praticar e demonstrar conhecimentos em **desenvolvimento web, HTML, CSS e JavaScript**, além de criar uma solução real para divulgação de uma empresa.
